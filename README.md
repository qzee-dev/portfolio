# Qoseem Oyerinmade Portfolio

A responsive portfolio for cloud infrastructure, DevSecOps,
platform engineering, Kubernetes, and automation projects.

## Project files

- `index.html` — page structure and project cards
- `styles.css` — styling, responsive layouts, and colour themes
- `script.js` — theme switching, mobile navigation, and footer year
- `images/` — portfolio and project architecture images

## Required image assets

Keep your existing `images/` directory and ensure it contains:

- `kubernetes.png`
- `Eks-production01.png`
- `DevSecOps-cicd.png`

If your image filenames differ, update the corresponding `src`
attributes in `index.html`.

The third featured project uses a built-in HTML/CSS architecture
diagram and does not require an additional image.

## Run locally

1. Open the project directory in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

Alternatively, open `index.html` directly in your browser.

## Customise

- Update the profile information and skills in `index.html`.
- Replace project descriptions and GitHub URLs with your actual repositories.
- Update the social links if your profile URLs change.
- Change the colour variables near the top of `styles.css`.
- Use the theme toggle to switch between dark and light modes.

## Important

The third project currently links to the GitHub profile because a
specific repository URL was not supplied. Replace that link with the
actual AWS networking repository URL when available.

The architecture illustration is a conceptual portfolio summary.
Ensure that project descriptions accurately reflect what you have
implemented and tested.
